# Seguro Auto — Vital Corretora

Landing page em Next.js publicada em `https://vital.net.br/seguro-automovel/`.

## Comandos

- `npm ci` instala as dependências bloqueadas pelo `package-lock.json`.
- `npm run dev` inicia o ambiente local.
- `npm run build` gera a exportação estática em `out/`.
- `npm audit` verifica vulnerabilidades conhecidas.

O deploy é acionado automaticamente após o envio para a branch `main`.
